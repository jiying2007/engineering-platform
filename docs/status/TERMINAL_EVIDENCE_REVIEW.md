# Terminal evidence review decision record

The terminal-blocker evidence contract is a forward-looking acceptance checklist. It cannot authorize external effects, transition any Recovery operation or close an issue by itself.

## Review rules

- Record exact protected-main commit and tree at the time of qualification, not an earlier proposal.
- Record raw positive and negative controls together. An inconclusive external effect, unavailable host or missing original receipt is `BLOCKED`, not `PASS`.
- Preserve distinct identities for the original dispatcher, reconciler, completion principal, and independent reviewer.
- Reject documents that silently substitute local test success for selected-host durability, latency, soak, mTLS or Provider evidence.
- After complete repository gates, treat host qualification as an additional independent stage; maintain internal readiness as blocked until both applicable issue criteria are met.

No readiness or deployment status is changed by this document.
