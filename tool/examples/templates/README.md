# 随发行包附带的三类任务模板

个人与小团队按任务类型复制一份 Markdown 到已有项目的 Issue/任务文件。只提供目标、已有材料和实际验收要求，不建立额外的 Work/Run 台账。无需连接外部模板仓库。

- [功能与变更](feature-change.md)
- [审查与发布准备](review-release.md)
